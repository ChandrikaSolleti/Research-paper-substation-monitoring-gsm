## My Role

**Project Lead & Researcher**

Led the development and publication of a microcontroller-based substation monitoring and control system using Arduino, GSM communication, multi-parameter sensing (V, I, f, T), and relay-based protection.

## Project Summary

The research presents a microcontroller-based system for remotely monitoring electrical parameters including voltage, current, frequency, and temperature. The system uses GSM communication to transmit monitored values and fault notifications, while relay-based protection isolates the load when predefined operating limits are exceeded.

## Key Technical Features

- Arduino-based monitoring and control
- GSM-based remote communication
- Three-phase current measurement using ACS712 sensors
- Frequency measurement using IC 555 timer circuits
- Temperature monitoring using LM35
- LCD-based parameter display
- Relay-based automatic load isolation
- SMS alerts for abnormal operating conditions
- Remote load control through GSM commands

## Practical Results

- Current protection limit: **1.6 A**
- Frequency operating range: **48–52 Hz**
- Current sensing: **3 phases**
- Temperature sensing: **LM35**
- Load test: **4 lamps**
- Relay capacity: **10 A**

The system demonstrated automatic load isolation during overload and abnormal-frequency conditions, with GSM messages communicating the detected condition and restoration status.
